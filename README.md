# 💻 Projet Personnel – Recréer mon site WordPress... à la main !

## 🌱 Objectif

Ce projet personnel a un but clair : **reprendre le contrôle sur mon site web**.  
Fini les coulisses toutes faites de WordPress, place au code pur, brut, élégant.  
L’idée ? Reproduire les fonctionnalités de mon site WordPress… mais uniquement avec du **HTML, CSS, JavaScript, PHP** – et surtout, **ma tête**.

## 🔧 Ce que je construis

- Une structure de site claire et responsive
- Un système de routing à la main (Front Controller, PHP)
- Une gestion des pages dynamiques
- Des formulaires faits maison
- Un design qui me ressemble, sans thème préfabriqué

## 🧠 Pourquoi ?

- Pour **comprendre ce que je fais**
- Pour **développer mes compétences en dev web**
- Pour **ne plus dépendre d’un CMS**
- Pour le **plaisir de bâtir de mes mains** ce que d’autres laissent à la machine

## 🛠️ Technologies utilisées

- `HTML5` pour la structure
- `CSS3` (et un peu de flexbox, parce que j’aime quand ça bouge)
- `JavaScript` pour quelques interactions
- `PHP` pour le back-end
- Et... **aucun plugin WordPress !**

## ✨ Ce projet m’apporte

> “Recréer, c’est comprendre. Repenser, c’est maîtriser.”

Chaque page, chaque formulaire, chaque ligne de PHP est une pierre posée sur le chemin de mon apprentissage. J’apprends à ne plus me cacher derrière un outil, mais à **le devenir**.

## 🎯 Prochaine étape

- Ajouter une base de données avec MySQL
- Implémenter un système de connexion
- Pourquoi pas… y greffer un petit CMS maison ?
